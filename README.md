# شوف بيت (ShoofBait): test site

Team test copy of the 360° walkthrough page. The working project lives in the private team-workspace repo
(`projects/real-estate/walk.html`); this repo only hosts a copy on GitHub Pages so the team can test on phones
(e.g. looking around by moving the phone), until shoofbait.com is ready.

- `index.html` = `walk.html`
- `tours/` = test tours: `sample-flat` (360° photos from a public photo site), `townhouse-f` (renders of our 3D model), `real-photo-test`.
